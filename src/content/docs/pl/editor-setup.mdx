Dostosuj swój edytor kodu aby poprawić doświadczenie programowania z Astro i odblokować nowe funkcje.

## VS Code

[VS Code](https://code.visualstudio.com/) to popularny edytor kodu dla twórców stron internetowych, stworzony przez Microsoft. Silnik VS Code zasila również popularne przeglądarkowe edytory kodu, takie jak [GitHub Codespaces](https://github.com/features/codespaces).

Astro działa z dowolnym edytorem kodu. VS Code jest jednak przez nas zalecany jeżeli chodzi o projekty Astro. Utrzymujemy oficjalne rozszerzenie [Astro dla VS Code](https://marketplace.visualstudio.com/items?itemName=astro-build.astro-vscode), które pozwala na korzystanie z kilku kluczowych funkcji i usprawnień dla deweloperów w projektach Astro.

- Podświetlanie składni w plikach `.astro`.
- Informacje o typach TypeScript w plikach `.astro`.
- [VS Code Intellisense](https://code.visualstudio.com/docs/editor/intellisense) do uzupełniania kodu, podpowiedzi i wiele więcej.

Aby zacząć już dziś, zainstaluj rozszerzenie [Astro dla VS Code](https://marketplace.visualstudio.com/items?itemName=astro-build.astro-vscode).

## Zed

[Zed](https://zed.dev/) to wydajny, wieloosobowy edytor kodu, zoptymalizowany pod kątem szybkości i dużych projektów. [Rozszerzenie Astro](https://zed.dev/extensions/astro) dodaje między innymi podświetlanie składni plików `.astro`, uzupełnianie kodu, formatowanie, diagnostykę i przechodzenie do definicji.

## JetBrains IDEs

[Webstorm](https://www.jetbrains.com/webstorm/) to IDE dla JavaScriptu i TypeScriptu, które w wersji 2024.2 dodało obsługę serwera języka Astro. Ta aktualizacja wprowadza między innymi podświetlanie składni, uzupełnianie kodu i formatowanie.

Zainstaluj oficjalną wtyczkę z [JetBrains Marketplace](https://plugins.jetbrains.com/plugin/20959-astro) albo wyszukaj „Astro” w zakładce Plugins w IDE. Serwer języka możesz włączać i wyłączać w `Settings | Languages & Frameworks | TypeScript | Astro`.

Więcej o wsparciu Astro w WebStormie znajdziesz w [oficjalnej dokumentacji Astro dla WebStorma](https://www.jetbrains.com/help/webstorm/astro.html).

## Edytory przeglądarkowe

Poza lokalnymi edytorami, Astro działa również dobrze w edytorach przeglądarkowych, w tym:

- [StackBlitz](https://stackblitz.com/) i [CodeSandbox](https://codesandbox.io/) - edytory online działające w przeglądarce, z wbudowanym podświetlaniem składni dla plików `.astro`. Nie wymagają instalacji ani konfiguracji!
- [GitHub.dev](https://github.dev/) - pozwala zainstalować rozszerzenie Astro dla VS Code jako [rozszerzenie webowe](https://code.visualstudio.com/api/extension-guides/web-extensions), co daje dostęp wyłącznie do niektórych funkcji pełnego rozszerzenia. Obecnie obsługiwane jest tylko podświetlanie składni.

## Inne narzędzia

### ESLint

[ESLint](https://eslint.org/) jest popularnym linterem dla JavaScript i JSX. Dla obsługi Astro można zainstalować [utrzymywany przez społeczność plugin](https://github.com/ota-meshi/eslint-plugin-astro).

Zobacz [wskazówki dla użytkowników](https://ota-meshi.github.io/eslint-plugin-astro/user-guide/) zawarte w projekcie, aby uzyskać więcej informacji na temat instalacji i konfiguracji ESLinta dla twojego projektu.

### Stylelint

[Stylelint](https://stylelint.io/) jest popularnym linterem dla CSS. [Utrzymywana przez społeczność konfiguracja Stylelint](https://github.com/ota-meshi/stylelint-config-html) zapewnia obsługę Astro.

Instrukcje instalacji, integrację z edytorem oraz dodatkowe informacje znajdziesz w README projektu.

### Biome

[Biome](https://biomejs.dev/) to linter i formater w jednym, przeznaczony dla webu. [Biome ma obecnie eksperymentalne wsparcie dla plików `.astro`](https://biomejs.dev/internals/language-support/#html-super-languages-support) i może lintować oraz formatować frontmatter w tych plikach.

### Prettier

[Prettier](https://prettier.io/) to popularny formater dla JavaScript, HTML, CSS i wielu innych języków. Jeśli korzystasz z [rozszerzenia Astro dla VS Code](https://marketplace.visualstudio.com/items?itemName=astro-build.astro-vscode), formatowanie kodu Prettierem jest już w nim zawarte.

Aby dodać formatowanie plików `.astro` poza edytorem (na przykład w CLI) albo w edytorach, które nie obsługują naszych narzędzi, zainstaluj [oficjalny plugin Prettier dla Astro](https://github.com/withastro/prettier-plugin-astro).

<Steps>
1. Zainstaluj `prettier` i `prettier-plugin-astro`.

    <PackageManagerTabs>
      <Fragment slot="npm">
      ```shell
      npm install --save-dev --save-exact prettier prettier-plugin-astro
      ```
      </Fragment>
      <Fragment slot="pnpm">
      ```shell
      pnpm add --save-dev --save-exact prettier prettier-plugin-astro
      ```
      </Fragment>
      <Fragment slot="yarn">
      ```shell
      yarn add --dev --exact prettier prettier-plugin-astro
      ```
      </Fragment>
    </PackageManagerTabs>

2. Utwórz plik konfiguracyjny `.prettierrc` (albo `.prettierrc.json`, `.prettierrc.mjs` lub [inny obsługiwany format](https://prettier.io/docs/configuration)) w katalogu głównym projektu i dodaj do niego `prettier-plugin-astro`.

    W tym pliku wskaż też ręcznie parser dla plików Astro.

    ```json title=".prettierrc"
    {
      "plugins": ["prettier-plugin-astro"],
      "overrides": [
        {
          "files": "*.astro",
          "options": {
            "parser": "astro"
          }
        }
      ]
    }
    ```

3. Opcjonalnie zainstaluj inne pluginy Prettier dla projektu i dodaj je do pliku konfiguracyjnego. Te dodatkowe pluginy mogą wymagać określonej kolejności. Na przykład przy Tailwindzie `prettier-plugin-tailwindcss` musi być [ostatnim pluginem Prettier w tablicy plugins](https://github.com/tailwindlabs/prettier-plugin-tailwindcss#compatibility-with-other-prettier-plugins).

    ```json title=".prettierrc"
    {
      "plugins": [
        "prettier-plugin-astro",
        "prettier-plugin-tailwindcss" // musi być ostatni
      ],
      "overrides": [
        {
          "files": "*.astro",
          "options": {
            "parser": "astro"
          }
        }
      ]
    }
    ```

4. Uruchom w terminalu poniższe polecenie, aby sformatować pliki.

    <PackageManagerTabs>
      <Fragment slot="npm">
      ```shell
      npx prettier . --write
      ```
      </Fragment>
      <Fragment slot="pnpm">
      ```shell
      pnpm exec prettier . --write
      ```
      </Fragment>
      <Fragment slot="yarn">
      ```shell
      yarn exec prettier . --write
      ```
      </Fragment>
    </PackageManagerTabs>
</Steps>

Zobacz [README plugina Prettier](https://github.com/withastro/prettier-plugin-astro/blob/main/README.md), aby dowiedzieć się więcej o obsługiwanych opcjach, konfiguracji Prettiera w VS Code i nie tylko.

### dprint

[dprint](https://dprint.dev/) to bardzo konfigurowalny formater kodu, który obsługuje wiele języków, w tym JavaScript, TypeScript, CSS i inne. Obsługę plików `.astro` można dodać za pomocą [pluginu markup_fmt](https://github.com/g-plane/markup_fmt).
