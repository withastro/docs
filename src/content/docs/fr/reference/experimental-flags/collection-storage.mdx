<p>

  **Type :** `"single-file" | "chunked" | { type: "chunked", chunkSize: number }`<br />
  **Par défaut :** `"single-file"`<br />
  <Since v="7.1.0" />
</p>

Cette fonctionnalité expérimentale vous permet de modifier la manière dont les données des collections de contenu sont conservées.

Par défaut, Astro conserve ces données dans un seul fichier à l'emplacement `.astro/data-store.json`. Lorsque l'option est définie sur `"chunked"`, Astro répartit les données entre plusieurs fichiers dans le dossier `.astro/data-store/`.

```js title="astro.config.mjs" ins={5}
import { defineConfig } from "astro/config";

export default defineConfig({
  experimental: {
    collectionStorage: "chunked"
  }
});
```

En mode `chunked`, les fichiers sont répartis en plusieurs fragments. Astro crée un nouveau fragment lorsque le fragment actuel dépasse 20 Mo.

Vous pouvez également modifier la limite. Cela est utile si votre environnement d'exécution ou votre hébergeur impose des limites spécifiques.

L'exemple suivant réduit la limite à 1 Mo :

```js title="astro.config.mjs" ins="chunkSize" ins={6-7}
import { defineConfig } from "astro/config";

export default defineConfig({
  experimental: {
    collectionStorage: {
      type: "chunked",
      chunkSize: 1024 * 1024
    }
  }
});
```

Cette option est recommandée lors du déploiement sur des plateformes imposant une limite de taille pour les ressources individuelles.
