> `new FetchState(request)` was called outside of an Astro server, so no manifest is available.

## 무엇이 잘못되었나요?

`new FetchState(request)`는 Astro가 사이트를 설명하는 매니페스트를 제공하는 Astro 서버 내부에서만 사용할 수 있습니다. 여기에는 빌드된 서버 출력물이나 개발 서버가 해당합니다. 이 오류는 일반 Node 스크립트에서 `astro/fetch`를 가져오는 경우처럼 다른 곳에서 호출되었음을 의미합니다.

Astro로 빌드된 서버 내부에서 이 오류가 발생하면 [이슈를 등록해 주세요](https://astro.build/issues/).
