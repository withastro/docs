Astro는 `@astrojs/markdown-remark` 패키지를 통해 인기 있는 Markdown 생태계인 [unified](https://unifiedjs.com/)에 대한 선택적 지원을 제공합니다. 이를 통해 remark와 rehype 플러그인을 사용하여 렌더링 과정을 사용자 지정하고 확장할 수 있습니다. 또한 통합이나 플러그인을 빌드할 때 유용한 도우미와 타입 집합을 제공합니다.

기능과 사용 예시는 Markdown 가이드의 [Markdown 프로세서](/ko/guides/markdown-content/#markdown-프로세서)를 참조하세요.

## `@astrojs/markdown-remark`에서 가져오기

다음 도우미는 `@astrojs/markdown-remark`에서 가져옵니다:

```ts
import {
  createMarkdownProcessor,
  isUnifiedProcessor,
  parseFrontmatter,
  rehypeHeadingIds,
  unified,
} from "@astrojs/markdown-remark";
```

### `createMarkdownProcessor()`

<p>

**타입:** <code>(opts?: <a href="#astromarkdownoptions">AstroMarkdownOptions</a>) => Promise\<<a href="#markdownrenderer">MarkdownRenderer</a>\></code><br />
<Since v="3.2.0" pkg="@astrojs/markdown-remark" />
</p>

독립 실행형 unified 기반 Markdown 렌더러를 생성합니다. 프로젝트에 구성된 [`markdown.processor`](/ko/reference/configuration-reference/#markdownprocessor)와 독립적으로 Markdown을 렌더링해야 할 때 유용합니다.

```ts title="src/utils/markdown.ts"
import { createMarkdownProcessor } from "@astrojs/markdown-remark";

const processor = await createMarkdownProcessor();
const { code, metadata } = await processor.render("# Hello world");
```

### `isUnifiedProcessor()`

<p>

**타입:** `(p: { name: string; }) => boolean`<br />
<Since v="7.2.0" pkg="@astrojs/markdown-remark" />
</p>

지정된 Markdown 프로세서가 unified인지 확인합니다. unified 전용 로직을 적용하기 전에 프로세서의 타입을 확인해야 할 때 유용합니다.

다음 예시는 통합 내에서 구성된 Markdown 프로세서가 unified인지 확인합니다:

```ts title="src/integrations/my-integration.ts" {9-11}
import { isUnifiedProcessor } from "@astrojs/markdown-remark";
import type { AstroIntegration } from "astro";

export default function myIntegration(): AstroIntegration {
  return {
    name: "my-integration",
    hooks: {
      "astro:config:done": ({ config }) => {
        if (isUnifiedProcessor(config.markdown.processor)) {
          // 여기에 unified 전용 로직을 적용합니다
        }
      },
    },
  };
}
```

### `rehypeHeadingIds()`

<p>

**타입:** <code><a href="#rehypeplugin">RehypePlugin</a></code><br />
<Since v="1.2.0" pkg="@astrojs/markdown-remark" />
</p>

Markdown 콘텐츠의 모든 제목에 대한 제목 ID를 생성하고 수집합니다. 이를 통해 [Markdown 콘텐츠를 가져오거나 렌더링할 때](/ko/guides/markdown-content/#사용-가능한-속성) 사용할 수 있습니다.

<ReadMore>사용 예시는 Markdown 가이드의 [제목 ID와 플러그인](/ko/guides/markdown-content/#제목-id와-플러그인)을 참조하세요.</ReadMore>

### `unified()`

<p>

**타입:** <code>(options?: <a href="#옵션">UnifiedProcessorOptions</a>) => <a href="#markdownprocessor">MarkdownProcessor</a></code><br />
<Since v="7.2.0" pkg="@astrojs/markdown-remark" />
</p>

`.md`와 `.mdx` 파일을 렌더링하기 위한 unified 기반 프로세서를 생성합니다. unified를 기본 Markdown 프로세서로 사용하려면 [`markdown.processor`](/ko/reference/configuration-reference/#markdownprocessor)에 전달하세요.

<ReadMore>예시와 함께 [Markdown 프로세서 설정하기](/ko/guides/markdown-content/#markdown-프로세서-설정하기)와 [remark 및 rehype 플러그인 사용하기](/ko/guides/markdown-content/#markdown-프로세서-플러그인)에 대해 자세히 알아보세요.</ReadMore>

#### 옵션

<p>

**타입:** `UnifiedProcessorOptions`
</p>

다음 옵션을 사용하여 unified 프로세서 동작을 사용자 지정할 수 있습니다.

##### `options.remarkPlugins`

<p>

**타입:** [`RemarkPlugins`](#remarkplugins)<br />
**기본값:** `[]`
</p>

[remark 플러그인](https://github.com/remarkjs/remark#plugins)을 전달하여 Markdown이 빌드되는 방식을 사용자 지정합니다. 플러그인 함수를 가져와 적용하거나(권장), 플러그인 이름을 문자열로 전달할 수 있습니다.

다음 예시는 사용자 지정 `heading` 옵션과 함께 [`remark-toc`](https://www.npmjs.com/package/remark-toc) 플러그인을 unified 프로세서에 전달합니다:

```js title="astro.config.mjs" {3,8}
import { defineConfig } from "astro/config";
import { unified } from "@astrojs/markdown-remark";
import remarkToc from "remark-toc";

export default defineConfig({
  markdown: {
    processor: unified({
      remarkPlugins: [[remarkToc, { heading: "contents" }]],
    }),
  },
});
```

##### `options.rehypePlugins`

<p>

**타입:** [`RehypePlugins`](#rehypeplugins)<br />
**기본값:** `[]`
</p>

[rehype 플러그인](https://github.com/rehypejs/rehype#plugins)을 전달하여 Markdown 콘텐츠에서 생성되는 HTML을 사용자 지정합니다. 플러그인 함수를 가져와 적용하거나(권장), 플러그인 이름을 문자열로 전달할 수 있습니다.

다음 예시는 [`rehype-accessible-emojis`](https://www.npmjs.com/package/rehype-accessible-emojis) 플러그인을 unified 프로세서에 전달합니다:

```js title="astro.config.mjs" {3,8}
import { defineConfig } from "astro/config";
import { unified } from "@astrojs/markdown-remark";
import { rehypeAccessibleEmojis } from "rehype-accessible-emojis";

export default defineConfig({
  markdown: {
    processor: unified({
      rehypePlugins: [rehypeAccessibleEmojis],
    }),
  },
});
```

##### `options.remarkRehype`

<p>

**타입:** [`RemarkRehype`](#remarkrehype)
</p>

[`remark-rehype`](https://github.com/remarkjs/remark-rehype) 플러그인에 옵션을 전달하여 Markdown이 HTML로 변환되는 방식을 제어합니다.

다음 예시는 각주 레이블을 사용자 지정합니다:

```js title="astro.config.mjs" {7-10}
import { defineConfig } from "astro/config";
import { unified } from "@astrojs/markdown-remark";

export default defineConfig({
  markdown: {
    processor: unified({
      remarkRehype: {
        footnoteLabel: "Footnotes",
        footnoteBackLabel: "Back to reference 1",
      },
    }),
  },
});
```

##### `options.recmaPlugins`

<p>

**타입:** `PluggableList`<br />
**기본값:** `[]`
</p>

[recma 플러그인](https://github.com/mdx-js/recma#plugins)을 전달하여 [MDX 파일](/ko/guides/integrations-guide/mdx/)의 [estree](https://github.com/estree/estree) 출력을 사용자 지정합니다. 이는 JavaScript 변수를 수정하거나 주입할 때 유용합니다.

```js title="astro.config.mjs" {3,8}
import { defineConfig } from "astro/config";
import { unified } from "@astrojs/markdown-remark";
import myRecmaPlugin from "./my-recma-plugin.mjs";

export default defineConfig({
  markdown: {
    processor: unified({
      recmaPlugins: [myRecmaPlugin],
    }),
  },
});
```

[AST Explorer](https://astexplorer.net/)를 사용하여 estree 출력을 실험해 볼 수 있으며, JavaScript 노드를 검색하려면 [`estree-util-visit`](https://unifiedjs.com/explore/package/estree-util-visit/)을 사용해 보세요.

##### `options.gfm`

<p>

**타입:** `boolean`<br />
**기본값:** `true`
</p>

[GitHub-Flavored Markdown(GFM)](https://github.com/remarkjs/remark-gfm) 지원을 활성화할지 비활성화할지 여부입니다.

이를 비활성화하려면 `gfm` 옵션을 `false`로 설정하세요:

```js title="astro.config.mjs" {7}
import { defineConfig } from "astro/config";
import { unified } from "@astrojs/markdown-remark";

export default defineConfig({
  markdown: {
    processor: unified({
      gfm: false,
    }),
  },
});
```

<ReadMore>Astro에서 [GitHub-Flavored Markdown](/ko/guides/markdown-content/#github-flavored-markdown) 사용하기에 대해 자세히 알아보세요.</ReadMore>

##### `options.smartypants`

<p>

**타입:** <code>boolean | <a href="#smartypants">Smartypants</a></code><br />
**기본값:** `true`
</p>

[SmartyPants 포매터](https://daringfireball.net/projects/smartypants/)를 사용하여 곧은따옴표를 둥근따옴표로, 대시를 en/em 대시로, 점 세 개를 줄임표로 변환할지 여부입니다.

비활성화하거나 [`retext-smartypants`에서 지원하는 속성](https://github.com/retextjs/retext-smartypants#fields)을 담은 구성 객체를 제공하여 동작을 사용자 지정할 수 있습니다.

다음 예시는 스마트 구두점 지원을 비활성화합니다:

```js title="astro.config.mjs" {7}
import { defineConfig } from "astro/config";
import { unified } from "@astrojs/markdown-remark";

export default defineConfig({
  markdown: {
    processor: unified({
      smartypants: false,
    }),
  },
});
```

<ReadMore>Markdown 가이드에서 [스마트 구두점](/ko/guides/markdown-content/#스마트-구두점) 구성하기에 대해 자세히 알아보세요.</ReadMore>
