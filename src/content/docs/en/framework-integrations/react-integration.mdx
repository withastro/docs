Procaptcha provides an [official React component](https://www.npmjs.com/package/@prosopo/react-procaptcha-wrapper) for easy integration of Prosopo Procaptcha into any React project.
The integration component supports all the [Procaptcha render options](/en/basics/client-side-rendering/#procaptcha-options).

## 1. Installation

`npm install @prosopo/react-procaptcha-wrapper`

## 2. Example of usage

### 2.1) Basic setup

```typescript jsx
import {ProcaptchaComponent} from "@prosopo/react-procaptcha-wrapper";

// ...

<ProcaptchaComponent siteKey={"my-site-key"}/>;
```

<GetSiteKey />

### 2.2) Advanced usage

```typescript jsx
// ...

<ProcaptchaComponent
    siteKey={siteKey}
    language={"en"}
    callback={(token: string): void => {
        console.log("verified", token);
    }}
    htmlAttributes={{
        className: "my-app__procaptcha",
        style: {
            maxWidth: "600px",
        },
    }}
/>
```
