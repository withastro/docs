This guide will help you set up the Procaptcha widget.

If you are currently using a CAPTCHA service, you can copy and paste our script wherever you have deployed the existing script today.

## Get a sitekey and secret key

To start using the Procaptcha widget, you will need to [obtain a sitekey and a secret key](https://prosopo.io/register/). The sitekey and secret key are always associated with one widget and cannot be reused for other widgets.

The sitekey is public and used to invoke the Procaptcha widget on your site.

Make sure you keep the secret key safe for security reasons.

<GetSiteKey />

### New sites

1. Log in to the [Prosopo user portal](https://portal.prosopo.io/) and navigate to Site Management.
2. Click to reveal your sitekey and secret key.
4. Copy your sitekey and secret key.

<Image src={PortalUserInfo} alt="get your site key from the Portal User Info" class="hide" />

### Set up your domain

1. Navigate to Account.
2. Make sure your domain is added to the list of domains. If not, add your domain.
3. `Allow localhost` if you are testing locally but make sure to remove it when you deploy your app.

<Image src={PortalDomainEditing} alt="edit a domain" class="hide" />

## Add the Procaptcha widget to your site

To add the Procaptcha widget:

1. Insert the Procaptcha script snippet in your HTML's `<head>` element:

<div>

```html
<script type="module" src="https://js.prosopo.io/js/procaptcha.bundle.js" async defer></script>
<script nomodule src="https://js.prosopo.io/js/procaptcha.bundle.iife.js" async defer></script>
```
</div>


2. [Rendering options](/en/basics/client-side-rendering/)

    * [Explicit rendering (recommended)](/en/basics/client-side-rendering/#explicit-rendering)
    * [Implicit rendering](/en/basics/client-side-rendering/#implicit-rendering)

## Verify the server-side response

After you have installed the Procaptcha widget on your site, you must configure your server to validate the Procaptcha response.
Refer to [Server-side verification](/en/basics/server-side-verification/).

### Important note
Rendering the [client-side integration](#add-the-procaptcha-widget-to-your-site) & [verifying the server-side response](/en/basics/server-side-verification/) are **both** necessary to allow Procaptcha to function properly.
