This experimental feature allows to change how the content collection data should store. 

By default - existing behavior - the data is stored in one single file inside `.astro/data-store.json`. With the option `chunked`, the data is split into multiple 
files inside the folder `.astro/data-store/`.

```js title="astro.config.mjs" ins={5}
import { defineConfig } from "astro/config";

export default defineConfig({
  experimental: {
    collectionStorage: "chunked"
  }
});
```

In chunked mode, files are split in multiple chunks. Astro creates a new chunk:
- each 1000 entries;
- a single chunk is bigger than 10Mb.

This option is recommended when working on platforms that have a size-limit on the assets.
