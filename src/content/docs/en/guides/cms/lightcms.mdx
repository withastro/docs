[LightCMS](https://lightcms.me/) is an open-source, Git-based headless CMS with a visual editor for writing Markdown and managing frontmatter. Content is committed directly to your own GitHub repository, so your Astro project keeps full version control and there is no vendor lock-in.

Because LightCMS writes plain Markdown and YAML frontmatter files, it works with Astro content collections without an SDK, API keys, or a build-time integration.

## Getting started

<Steps>
1. Sign in to [LightCMS](https://lightcms.me/) with your GitHub account and grant it access to the repository containing your Astro project.

2. Select the repository and branch you want to edit, then choose the folder that holds your content (for example, `src/content/blog`).

3. Create or edit entries in the visual editor. LightCMS generates clean Markdown and frontmatter that match your existing content collection schema.

4. Publish your changes. LightCMS commits them to your chosen branch, or opens a pull request for review if you prefer a workflow with approvals.

5. Your existing deployment pipeline (GitHub Actions, Netlify, Vercel, Cloudflare Pages) builds and deploys the site as usual.
</Steps>

:::tip
The [LightCMS Astro blog template](https://github.com/light-cms/astro_blog) is a working Astro + Starlight blog with sample content and a GitHub Actions workflow you can use as a starting point.
:::
