[EmDash](https://emdashcms.com/) is an open-source, full-stack CMS built specifically for Astro, adding database-backed content, an admin UI, a media library, menus, and taxonomies to your site.

## Official Resources

- [EmDash for Astro Developers](https://docs.emdashcms.com/coming-from/astro/) explains how EmDash extends an Astro project.
- [EmDash on GitHub](https://github.com/emdash-cms/emdash)
