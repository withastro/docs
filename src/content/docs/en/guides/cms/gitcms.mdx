[GitCMS](https://gitcms.dev/) is a CMS for code-first Astro sites, including sites built with AI coding agents. Your team and clients can edit, review, and publish Markdown and MDX content, plus JSON, YAML, and TOML data files, in a visual editor. AI agents can take part in the same workflow through MCP. Content stays in your GitHub repository, and every change is a Git commit.
