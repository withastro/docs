[Wix Headless](https://www.wix.com/headless) can host Astro sites on a managed infrastructure and connects them to Wix business services (e.g. bookings, online stores).

This guide shows how to connect an existing Astro project to Wix and deploy it with the Wix CLI.

## Prerequisites

- A [Wix account](https://www.wix.com/).
- Node.js v24.22.1 or higher, which the Wix CLI requires.
- An Astro 5 or Astro 7 project. Wix does not support Astro 6.

## Project configuration

<Steps>
1. In the root folder of your Astro project, run the following command and enter a business name when prompted:

    ```bash
    npm create @wix/new@latest -- headless link
    ```

    This creates a Wix site for your project and a `wix.config.json` file that links the two. It also updates your project to use Wix's Astro integration and the `@wix/astro-wix-hosting-adapter` adapter, sets `output: 'server'`, and replaces your `package.json` scripts with ones that run through the Wix CLI.

2. Start the development server to check that your project runs:

    ```bash
    npm run dev
    ```
</Steps>

To start a new project instead, run `npm create @wix/new@latest headless` and choose one of the [Wix Astro templates](https://github.com/wix/headless-templates/tree/main/astro).

## How to deploy

<Steps>
1. Build your project:

    ```bash
    npx wix build
    ```

2. (Optional) Upload this build to a preview URL that you can share without publishing it:

    ```bash
    npx wix preview
    ```

3. Publish your site:

    ```bash
    npx wix release
    ```

    The CLI shows the URL of your published site. Each release also clears the site's cache.
</Steps>
