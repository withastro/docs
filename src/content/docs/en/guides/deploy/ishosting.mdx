[is\*hosting](https://ishosting.com/) is a hosting provider offering VPS and dedicated servers in 40+ locations that you can use to self-host a static or server-rendered (SSR) Astro site.
 A VPS is suitable when your Astro site uses SSR and requires a persistent server, database connections, background jobs, cron jobs, or API routes.

 ## Project configuration

 Your Astro project can be deployed to an is\*hosting VPS as a static site or as an on-demand rendered site.

 ### Static site

 Your Astro project is a static site by default. You don't need any extra Astro configuration to deploy a static site to an is\*hosting VPS.

 ### Adapter for on-demand rendering

 To enable on-demand rendering in your Astro project and deploy it to an is\*hosting VPS, add [the Node.js adapter](/en/guides/integrations-guide/node/).

 ## Prerequisites

 To deploy your Astro site to an is\*hosting VPS, you will need:

 - An Astro project
 - An is\*hosting VPS running Ubuntu with SSH access and `root` or `sudo` privileges
 - A domain name pointing to your VPS
- A Node.js version that meets [Astro's minimum requirements](/en/install-and-setup/#prerequisites) installed on your VPS

 Connect to your VPS using SSH and update the installed packages:

 ```shell
 ssh root@YOUR_VPS_IP
 apt update && apt upgrade -y
 ```

 Install Node.js 22 and Nginx:

 ```shell
 curl -fsSL https://deb.nodesource.com/setup_22.x | bash -
 apt install -y nodejs nginx
 ```

 Verify the Node.js installation:

 ```shell
 node --version
 npm --version
 ```

 The server commands in this guide assume you are logged in as `root`. If you use another account, run administrative commands with `sudo`. The installation commands require `curl` to be available, and cloning a repository requires `git`.

 ## Deploy an SSR Astro Site

 For an Astro site using on-demand rendering, configure the Node.js adapter in `standalone` mode and run the generated server behind an Nginx reverse proxy.

 1. Add the Node.js adapter to your Astro project. Run the appropriate command in your local Astro project, then commit the configuration changes before deploying.

 	Choose your package manager:

 	**npm:**

 	```shell
 	npx astro add node
 	```

 	**pnpm:**

 	```shell
 	pnpm astro add node
 	```

 	**yarn:**

 	```shell
 	yarn astro add node
 	```

 2. Configure the adapter to use `standalone` mode in `astro.config.mjs`:

 	```js
 	import { defineConfig } from 'astro/config';
 	import node from '@astrojs/node';

 	export default defineConfig({
   	output: 'server',
   	adapter: node({
     	mode: 'standalone',
   	}),
 	});
 	```

 3. Copy or clone your Astro project to the VPS and install its dependencies:

 	```shell
 	cd /var/www
 	git clone YOUR_REPOSITORY_URL astro
 	cd astro
 	npm install
 	```

 	Replace `YOUR_REPOSITORY_URL` with the URL of your repository.

 4. Build your Astro site:

 	```shell
 	npm run build
 	```

 	The standalone Node.js server entry point will be generated at `dist/server/entry.mjs`.

 5. Install PM2:

 	```shell
 	npm install -g pm2
 	```

 6. Start the Astro server with PM2:

 	```shell
 	HOST=127.0.0.1 PORT=4321 pm2 start dist/server/entry.mjs --name astro-app
 	```

 7. Verify that the process is running:

 	```shell
 	pm2 status
 	```

 8. Configure PM2 to restore the process after a server restart:

 	```shell
 	pm2 startup
 	```

 	Run the command printed by PM2, then save the current process list:

 	```shell
 	pm2 save
 	```

 9. Create an Nginx configuration for your Astro site:

 	```shell
 	nano /etc/nginx/sites-available/astro
 	```

 10. Add the following configuration, replacing `your.domain.com` with your domain:

 	```nginx
 	server {
     	listen 80;
     	server_name your.domain.com;

     	location / {
         	proxy_pass http://127.0.0.1:4321;
         	proxy_http_version 1.1;
         	proxy_set_header Host $host;
         	proxy_set_header X-Real-IP $remote_addr;
         	proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
         	proxy_set_header X-Forwarded-Proto $scheme;
     	}
 	}
 	```

 11. Enable the Nginx configuration and reload Nginx:

 	```shell
 	ln -s /etc/nginx/sites-available/astro /etc/nginx/sites-enabled/astro
 	nginx -t
 	systemctl reload nginx
 	```


 Your Astro SSR site is now served through Nginx, which forwards incoming requests to the Node.js process running on `127.0.0.1:4321`.

 ## Deploy a Static Astro Site

 For a static Astro site, build your project and serve the generated `dist/` directory directly with Nginx. A persistent Node.js process is not required.

 1. Copy or clone your Astro project to the VPS, install its dependencies, and build the site:

 	```shell
 	cd /var/www
 	git clone YOUR_REPOSITORY_URL astro
 	cd astro
 	npm install
 	npm run build
 	```

 2. Create an Nginx configuration:

 	```shell
 	nano /etc/nginx/sites-available/astro
 	```

 3. Add the following configuration, replacing `your.domain.com` with your domain:

 	```nginx
 	server {
     	listen 80;
     	server_name your.domain.com;

     	root /var/www/astro/dist;
     	index index.html;

     	location / {
         	try_files $uri $uri/ $uri.html =404;
     	}
 	}
 	```

 4. Enable the configuration and reload Nginx:

 	```shell
 	ln -s /etc/nginx/sites-available/astro /etc/nginx/sites-enabled/astro
 	nginx -t
 	systemctl reload nginx
 	```


 Your static Astro site is now served directly from the generated `dist/` directory.

 ### Add HTTPS

 After your domain points to the VPS, you can use Certbot to configure HTTPS for either a static or SSR deployment. Make sure ports 80 and 443 are accessible.

<Steps>
1. Install Certbot and its Nginx plugin:

   ```shell
   apt install -y certbot python3-certbot-nginx
   ```

2. Request a certificate for your domain:

   ```shell
   certbot --nginx -d your.domain.com
   ```

   Replace `your.domain.com` with your domain and follow the prompts.

3. Test automatic certificate renewal:

   ```shell
   certbot renew --dry-run
   ```
</Steps>

### Update your site

To deploy changes to your site, pull the latest changes, install dependencies, and rebuild your site:

```shell
cd /var/www/astro
git pull
npm install
npm run build
```

If your site is on-demand rendered, restart the PM2 process for the changes to take effect:

```shell
pm2 restart astro-app
```
