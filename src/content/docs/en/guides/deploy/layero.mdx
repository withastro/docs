You can deploy your Astro project to [Layero](https://layero.ru/), a hosting platform with build servers and a CDN located in Russia.

Layero detects Astro automatically, so the build command and the output directory are filled in for you.

## How to deploy from a GitHub repository

<Steps>
1. [Create a Layero account](https://app.layero.ru/) and install the Layero GitHub App for the repository you want to deploy.

2. Create a project and pick that repository. Layero reads your `package.json`, recognises Astro, and proposes `npm run build` with the `dist` output directory. Adjust them only if your project differs from the defaults.

3. Confirm. The first build starts immediately, and every later push to the default branch triggers a new one. Other branches get their own preview URLs.
</Steps>

## How to deploy from the command line

Use this path when your repository is not on GitHub, or when the build needs secrets you would rather keep in your own CI.

<Steps>
1. Install the CLI and sign in. The device flow prints a code and a URL, so it also works over SSH:

    ```bash
    npx layero@latest login
    ```

2. From the project directory, deploy:

    ```bash
    npx layero@latest deploy
    ```

    The CLI runs the build, uploads `dist`, and prints the public URL. Pass `--prebuilt dist` to upload an existing build instead of running one.
</Steps>

<ReadMore>Read more in the [Layero documentation](https://docs.layero.ru/en/), or see [how frameworks are detected](https://docs.layero.ru/en/getting-started/frameworks) for the exact build command and output directory Layero uses for Astro.</ReadMore>
