[Docusaurus](https://Docusaurus.io) es un popular constructor de sitios web de documentación, desarrollado con React.

## Similitudes clave entre Docusaurus y Astro

Docusaurus y Astro comparten algunas similitudes que te ayudarán a migrar tu proyecto:

- Tanto Astro como Docusaurus son constructores modernos basados en JavaScript (Jamstack) diseñados para [sitios web orientados al contenido](/es/concepts/why-astro/#orientado-al-contenido), como los sitios de documentación. 

- Tanto Astro como Docusaurus soportan [páginas MDX](/es/guides/markdown-content/). Deberías poder usar tus archivos `.mdx` existentes con Astro.

- Tanto Astro como Docusaurus usan [enrutamiento basado en archivos](/es/guides/routing/) para generar rutas de páginas automáticamente para cada archivo MDX dentro de `src/pages`. Usar la estructura de archivos de Astro para tu contenido existente y al añadir páginas nuevas debería resultarte familiar.

- Astro tiene una [integración oficial para usar componentes de React](/es/guides/integrations-guide/react/). Toma encuenta que, en Astro, los archivos de React **deben** tener una extensión `.jsx` o `.tsx`.

- Astro soporta [instalar paquetes NPM](/es/guides/imports/#npm-packages), incluidos varios para React. Puede que puedas conservar algunos o todos tus componentes y dependencias de React.

- [La sintaxis de Astro similar a JSX](/es/basics/astro-components/#maquetado-del-componente) debería resultarte familiar si estás acostumbrado a escribir React.


## Diferencias clave entre Docusaurus y Astro

Cuando reconstruyas tu sitio de Docusaurus en Astro, notarás algunas diferencias importantes:

- Docusaurus es una aplicación de página única (single-page application (SPA)) basada en React. Los sitios de astro son aplicaciones de varias páginas creadas con [componentes `.astro`](/es/basics/astro-components/), pero también puede soportar [React, Preact, Vue.js, Svelte, SolidJS, AlpineJS](/es/guides/framework-components/) así como plantillas HTML sin procesar.

- Docusaurus fue diseñado para construir sitios web de documentación y cuenta con algunas funcionalidades específicas para documentación que tendrías que construir por ti mismo en Astro. Por otro lado, Astro ofrece algunas de estas funcionalidades mediante [Starlight: un tema oficial de documentación](https://starlight.astro.build). Este sitio web fue la inspiración para Starlight, ¡y ahora funciona con él! Puedes encontrar más [temas de documentación de la comunidad](https://astro.build/themes?search=&categories%5B%5D=docs) con funcionalidades integradas en nuestra galería de temas.

- Los sitios web de Docusaurus usan páginas MDX para el contenido. El tema de documentación de Astro usa archivos Markdown (`.md`) de forma predeterminada y no requiere que uses MDX. Opcionalmente puedes [instalar la integración MDX de Astro](/es/guides/integrations-guide/mdx/) (incluida de forma predeterminada en nuestro tema Starlight) y usar archivos `.mdx` además de archivos Markdown estándar.


## Cambia de Docusaurus a Astro

Para convertir un sitio de documentación en Docusaurus a Astro, comienza con nuestra [plantilla oficial de inicio del tema de Starlight](https://starlight.astro.build), o explora más temas de documentación de la comunidad en nuestra [galería de temas](https://astro.build/themes?search=&categories%5B%5D=docs). 

Puedes pasar el argumento `--template` al comando `create astro` para iniciar un nuevo proyecto de Astro con una de nuestras plantillas oficiales de inicio. O puedes [iniciar un nuevo proyecto desde cualquier repositorio de Astro existente en GitHub](/es/install-and-setup/#instala-desde-el-asistente-cli).

  <PackageManagerTabs>
    <Fragment slot="npm">
    ```shell
    npm create astro@latest -- --template starlight
    ```
    </Fragment>
    <Fragment slot="pnpm">
    ```shell
    pnpm create astro@latest --template starlight
    ```
    </Fragment>
    <Fragment slot="yarn">
    ```shell
    yarn create astro --template starlight
    ```
    </Fragment>
  </PackageManagerTabs>

La integración MDX de Astro se incluye de forma predeterminada, así que puedes [llevar tus archivos de contenido existentes a Starlight](https://starlight.astro.build/es/getting-started/#a%C3%B1ade-contenido) de inmediato.

Puedes encontrar la plantilla inicial de documentación de Astro, y otras plantillas oficiales, en [astro.new](https://astro.new). Encontrarás un enlace al repositorio de GitHub de cada proyecto, así como enlaces de un solo clic para abrir un proyecto funcional en los entornos de desarrollo de StackBlitz y CodeSandbox.
