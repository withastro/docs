[Eleventy](https://11ty.dev) es un generador de sitios estáticos de código abierto que funciona con múltiples lenguajes de plantillas.

## Similitudes clave entre Eleventy (11ty) y Astro

Eleventy (11ty) y Astro comparten algunas similitudes que te ayudarán a migrar tu proyecto:

- Tanto Astro como Eleventy son generadores de sitios modernos basados en JavaScript (Jamstack).

- Tanto Astro como Eleventy te permiten usar un [CMS headless, APIs o archivos Markdown para los datos](/es/guides/data-fetching/). Puedes continuar usando tu sistema preferido de creación de contenido y podrás conservar tu contenido existente.

## Diferencias clave entre Eleventy (11ty) y Astro

Cuando reconstruyas tu sitio de Eleventy (11ty) en Astro, notarás algunas diferencias importantes:

- Eleventy admite una variedad de lenguajes de plantillas. Astro admite [la inclusión de componentes de varios frameworks populares de JS (por ejemplo, React, Svelte, Vue, Solid)](/es/guides/framework-components/), pero utiliza [layouts, páginas y componentes de Astro](/es/basics/astro-components/) para la mayoría de las plantillas de página.

- Astro utiliza un [directorio `src/`](/es/basics/project-structure/#src) para todos los archivos, incluidos los metadatos del sitio, que están disponibles para consultar y procesar durante la compilación del sitio. Dentro de este hay una [carpeta especial `src/pages/` para el enrutamiento basado en archivos](/es/basics/astro-pages/).

- Astro utiliza una [carpeta `public/` para recursos estáticos](/es/basics/project-structure/#public) que no necesitan ser procesados ni transformados durante la compilación.

- En Eleventy, el empaquetado de CSS, JavaScript y otros recursos debe configurarse manualmente. [Astro se encarga de esto por ti de forma predeterminada](/es/concepts/why-astro/#fácil-de-usar).

## Cambia de Eleventy a Astro

Para convertir un blog de Eleventy a Astro, comienza con nuestra plantilla inicial de tema de blog, o explora más temas de blog de la comunidad en nuestro [escaparate de temas](https://astro.build/themes/).

Puedes pasar un argumento `--template` al comando `create astro` para iniciar un nuevo proyecto de Astro con una de nuestras plantillas oficiales de inicio. O puedes [iniciar un nuevo proyecto desde cualquier repositorio existente de Astro en GitHub](/es/install-and-setup/#instala-desde-el-asistente-cli).

  <PackageManagerTabs>
    <Fragment slot="npm">
    ```shell
    npm create astro@latest -- --template blog
    ```
    </Fragment>
    <Fragment slot="pnpm">
    ```shell
    pnpm create astro@latest --template blog
    ```
    </Fragment>
    <Fragment slot="yarn">
    ```shell
    yarn create astro --template blog
    ```
    </Fragment>
  </PackageManagerTabs>

 Trae tus archivos Markdown existentes (o MDX, con nuestra integración opcional) como contenido para [crear páginas Markdown o MDX](/es/guides/markdown-content/).

Tu proyecto de Eleventy te permitía usar una variedad de lenguajes de plantillas para construir tu sitio. En un proyecto de Astro, la creación de plantillas de página se realizará principalmente con componentes de Astro, que pueden usarse como elementos de interfaz de usuario, layouts e incluso páginas completas. Quizás quieras explorar la [sintaxis de componentes de Astro](/es/basics/astro-components/) para ver cómo crear plantillas en Astro usando componentes.

Para convertir otros tipos de sitios, como un portafolio o un sitio de documentación, consulta más plantillas oficiales de inicio en [astro.new](https://astro.new). Encontrarás un enlace al repositorio de GitHub de cada proyecto, así como enlaces de un solo clic para abrir un proyecto en funcionamiento en los entornos de desarrollo en línea StackBlitz y CodeSandbox.
