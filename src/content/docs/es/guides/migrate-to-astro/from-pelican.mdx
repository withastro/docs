[Pelican](https://getpelican.com) es un generador de sitios estáticos de código abierto construido en Python.

## Similitudes clave entre Pelican y Astro

Pelican y Astro comparten algunas similitudes que te ayudarán a migrar tu proyecto:

- Tanto Pelican como Astro son generadores de sitios estáticos, ideales para [sitios web orientados al contenido](/es/concepts/why-astro/#orientado-al-contenido) como los blogs.

- Tanto Pelican como Astro tienen soporte integrado para [escribir en Markdown](/es/guides/markdown-content/), incluidas las propiedades YAML de frontmatter para los metadatos de la página. Sin embargo, Astro tiene muy pocas propiedades de frontmatter reservadas en comparación con Pelican. Aunque muchas de tus propiedades existentes de frontmatter de Pelican no serán "especiales" en Astro, puedes continuar usando tus archivos Markdown y valores de frontmatter existentes.

## Diferencias clave entre Pelican y Astro

Cuando reconstruyas tu sitio de Pelican en Astro, notarás algunas diferencias importantes:

- Pelican admite escribir contenido en Markdown y reStructuredText (`.rst`). Astro admite [crear páginas a partir de archivos Markdown y MDX](/es/guides/markdown-content/), pero no admite reStructuredText.

- Pelican utiliza archivos HTML y la sintaxis Jinja para las plantillas. La [sintaxis de Astro](/es/basics/astro-components/) es un superconjunto de HTML similar a JSX. Todo el HTML válido es sintaxis `.astro` válida.

- Pelican fue diseñado para construir sitios web ricos en contenido como blogs y tiene algunas características integradas para blogs que tendrías que construir tú mismo en Astro. En su lugar, Astro ofrece algunas de estas características incluidas en un [tema oficial de blog](https://github.com/withastro/astro/tree/latest/examples/blog).

## Cambia de Pelican a Astro

Para convertir un sitio de documentación de Pelican a Astro, comienza con nuestra [plantilla inicial oficial de tema de documentación Starlight](https://starlight.astro.build), o explora más temas de la comunidad en nuestro [escaparate de temas](https://astro.build/themes/).

Puedes pasar un argumento `--template` al comando `create astro` para iniciar un nuevo proyecto de Astro con una de nuestras plantillas iniciales oficiales. O puedes [iniciar un nuevo proyecto desde cualquier repositorio existente de Astro en GitHub](/es/install-and-setup/#instala-desde-el-asistente-cli).

  <PackageManagerTabs>
    <Fragment slot="npm">
    ```shell
    npm create astro@latest -- --template starlight
    ```
    </Fragment>
    <Fragment slot="pnpm">
    ```shell
    pnpm create astro@latest --template starlight

    <Fragment slot="yarn">

    ```

  </PackageManagerTabs>

Trae tus archivos de contenido Markdown existentes para [crear páginas Markdown](/es/guides/markdown-content/). Aún puedes aprovechar el [enrutamiento basado en archivos](/es/guides/routing/) copiando estos documentos desde la carpeta `content/` de Pelican hacia `src/pages/` en Astro. Quizás desees leer sobre la [estructura de proyectos de Astro](/es/basics/project-structure/) para aprender dónde deben ubicarse los archivos.

Es posible que Pelican haya manejado gran parte del layout y los metadatos de tu sitio por ti. Quizás desees leer sobre [cómo construir layouts de Astro como contenedores de páginas Markdown](/es/basics/layouts/#plantillas-de-markdown) para ver cómo gestionar las plantillas tú mismo en Astro, incluido el `<head>` de tu página.

Al igual que Pelican, Astro tiene muchos plugins que extienden su funcionalidad. Explora la [lista oficial de integraciones](/es/guides/integrations/) para agregar características como soporte para MDX, y encuentra cientos más de integraciones mantenidas por la comunidad en el [Directorio de Integraciones de Astro](https://astro.build/integrations/). Incluso puedes usar la [API de Integración de Astro](/es/reference/integrations-reference/) para construir tu propia integración personalizada para extender las características de tu proyecto.

Para convertir otros tipos de sitios, como un portafolio o un blog, consulta más plantillas iniciales oficiales en [astro.new](https://astro.new). Encontrarás un enlace al repositorio de GitHub de cada proyecto, así como enlaces de un solo clic para abrir un proyecto en funcionamiento en los entornos de desarrollo en línea StackBlitz y CodeSandbox.
