[Prisma Postgres](https://www.prisma.io/) es una base de datos Postgres totalmente gestionada y sin servidor, diseñada para aplicaciones web modernas.

## Conectar con Prisma ORM (recomendado)

[Prisma ORM](https://www.prisma.io/orm) es la forma recomendada de conectarse a tu base de datos Prisma Postgres. Proporciona consultas seguras en cuanto a tipos, migraciones y rendimiento global.

Esta guía utiliza Prisma ORM 8. Si estás en Prisma ORM 7, sigue la [guía de Prisma ORM 7 para Astro en la documentación de Prisma](https://www.prisma.io/docs/guides/v7/frameworks/astro) en su lugar.

### Prerrequisitos
- Un proyecto de Astro con un adaptador instalado para habilitar [el renderizado bajo demanda (SSR)](/es/guides/on-demand-rendering/).
- Una versión de Node.js que cumpla con los [requisitos mínimos de Astro](/es/install-and-setup/#prerrequisitos). Si estás en Node.js v24, asegúrate de usar `v24.11.0` o superior para cumplir con los requisitos de Prisma ORM 8.

### Instalar dependencias e inicializar Prisma

Ejecuta el siguiente comando en tu proyecto para instalar Prisma ORM y crear sus archivos iniciales:

```bash
npx prisma@latest orm init --target postgres --authoring psl
```

Esto instala la CLI de `prisma`, `@prisma/orm-postgres` y `dotenv`, y crea:
- Un archivo `prisma.config.ts` que carga tu `DATABASE_URL` desde `.env`
- Un archivo `src/prisma/contract.prisma` con un modelo de datos inicial
- Un archivo `src/prisma/db.ts` que exporta el cliente de Prisma ORM
- Un archivo `.env.example`

Si ya tienes una base de datos Prisma Postgres, añade su cadena de conexión a `.env` como `DATABASE_URL`. De lo contrario, ejecuta el siguiente comando para crear una base de datos y escribir automáticamente su cadena de conexión:

```bash
npx create-db@latest --env .env
```

El comando muestra una URL de reclamación. Ábrela e inicia sesión para conservar la base de datos. Prisma elimina las bases de datos no reclamadas después de 24 horas.

### Define un Modelo

Prisma requiere al menos un modelo en el contrato para crear las tablas de la base de datos. El siguiente ejemplo define un modelo `Post` como marcador de posición. Reemplaza el contenido de `src/prisma/contract.prisma` con él para comenzar. Puedes eliminarlo o sustituirlo más adelante por modelos que reflejen tus datos reales.

```prisma title="src/prisma/contract.prisma"
// use prisma-8

model Post {
  id        Int     @id @default(autoincrement())
  title     String
  content   String?
  published Boolean @default(false)
}
```

Mantén la línea `// use prisma-8` en la parte superior del archivo: le indica a Prisma qué sintaxis de contrato utiliza el archivo. Obtén más información sobre cómo configurar tu instalación de Prisma ORM en la [referencia de contratos de Prisma](https://www.prisma.io/docs/orm/contract-authoring/psl-syntax).

### Emitir el contrato

Ejecuta el siguiente comando para generar los archivos tipados que importa `src/prisma/db.ts`. Ejecútalo nuevamente cada vez que cambies tu contrato:

```bash
npx prisma contract emit
```

### Crear las tablas de la base de datos

Ejecuta el siguiente comando para crear las tablas a partir de tu contrato. Esto también crea un directorio `migrations/` que registra el estado de tu base de datos:

```bash
npx prisma db init
```

Si el comando se detiene con `Connection terminated unexpectedly`, una base de datos que acabas de crear aún se está iniciando. Espera unos segundos y ejecútalo de nuevo.

Después de cambiar tu contrato, ejecuta `npx prisma db update` nuevamente para aplicar el cambio a tu base de datos.

### Consulta y visualización de datos

El cliente `db` exportado desde `src/prisma/db.ts` se crea una vez y se reutiliza en todo tu proyecto. Los modelos se agrupan por su esquema de PostgreSQL, por lo que el modelo `Post` está disponible como `db.orm.public.Post`.

El siguiente ejemplo muestra cómo recuperar solo tus publicaciones publicadas, ordenadas por `id` y, a continuación, mostrar los títulos y el contenido de las publicaciones en tu plantilla de Astro:

```astro title="src/pages/posts.astro" {2, 4-7}
---
import { db } from '../prisma/db';

const posts = await db.orm.public.Post
  .where({ published: true })
  .orderBy((post) => post.id.desc())
  .all();
---

<html>
  <head>
    <title>Artículos publicados</title>
  </head>
  <body>
    <h1>Artículos publicados</h1>
    <ul>
      {posts.map((post) => (
        <li>
          <h2>{post.title}</h2>
          {post.content && <p>{post.content}</p>}
        </li>
      ))}
    </ul>
  </body>
</html>
```

Lo mejor es gestionar las consultas en una ruta API. Para obtener más información sobre cómo utilizar Prisma ORM en tu proyecto de Astro, consulta la [Guía de Astro + Prisma ORM](https://www.prisma.io/docs/guides/frameworks/astro) y la [guía de Prisma para leer datos](https://www.prisma.io/docs/orm/fundamentals/reading-data).

## Conectar con otros ORMs y bibliotecas

Puedes conectarte a Prisma Postgres a través de TCP directo usando cualquier otro ORM, biblioteca de base de datos o herramienta de tu preferencia. Crea una cadena de conexión directa en tu Prisma Console para empezar.

### Requisitos previos
- Un proyecto de Astro con un adaptador instalado para habilitar el [renderizado bajo demanda (SSR)](/es/guides/on-demand-rendering/).
- Una base de datos de [Prisma Postgres](https://pris.ly/ppg) con una cadena de conexión con TCP habilitado.

### Instalar dependencias

Este ejemplo usa [`pg`, un cliente PostgreSQL para Node.js](https://github.com/brianc/node-postgres) para realizar una conexión TCP directa.

Ejecuta el siguiente comando para instalar el paquete `pg`:

```bash
npm install pg
```

### Consulta tu cliente de base de datos

Proporciona tu cadena de conexión al cliente `pg` para comunicarse con tu servidor SQL y obtener datos de tu base de datos.

El siguiente ejemplo de creación de una tabla e inserción de datos se puede utilizar para validar la URL de consulta y la conexión TCP:

```astro title="src/pages/index.astro" {2-19}
---
import { Client } from 'pg';
const client = new Client({ 
  connectionString: import.meta.env.DATABASE_URL,
  ssl: { rejectUnauthorized: false }
});
await client.connect();

await client.query(`
  CREATE TABLE IF NOT EXISTS posts (
    id SERIAL PRIMARY KEY,
    title TEXT UNIQUE,
    content TEXT
  );
  
  INSERT INTO posts (title, content)
  VALUES ('Hello', 'World')
  ON CONFLICT (title) DO NOTHING;
`);

const { rows } = await client.query('SELECT * FROM posts');
await client.end();
---

<h1>Artículos</h1>
<p>{rows[0].title}: {rows[0].content}</p>
```
