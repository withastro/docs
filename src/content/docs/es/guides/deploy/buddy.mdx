Puedes desplegar tu proyecto de Astro usando [Buddy](https://buddy.works/), una solución de CI/CD que puede construirtu sitio y enviarlo a múltiples destinos de despliegue, incluyendo servidores FTP y proveedores de alojamiento en la nube.

:::note
El propio Buddy no alojará tu sitio. En su lugar, te ayuda a gestionar el proceso de construcción y a entregar el resultado a la plataforma de despliegue de tu elección.
:::

## Cómo realizar el despliegue

<Steps>
1. [Crea una cuenta en **Buddy**](https://buddy.works/sign-up).

2. Crea un nuevo proyecto y conéctalo con un repositorio Git (GitHub, GitLab, BitBucket, cualquier repositorio Git privado o puedes usar el alojamiento Git de Buddy).

3. Añade un nuevo pipeline.

4. En el pipeline recién creado, añade una acción de **[Node.js](https://buddy.works/actions/node-js)**.

5. En esta acción añade:

   ```bash
   npm install
   npm run build
   ```

6. Añade una acción de despliegue — hay muchas para elegir, puedes explorarlas en el [catálogo de acciones de Buddy](https://buddy.works/actions). Aunque sus configuraciones pueden variar, recuerda establecer la **Ruta de origen** en `dist`.

7. Presiona el botón **Run**.
</Steps>
