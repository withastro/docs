[Netlify](https://netlify.com) ofrece alojamiento y servicios de backend serverless para aplicaciones web y sitios web estáticos. ¡Cualquier sitio Astro puede alojarse en Netlify!

Esta guía incluye instrucciones para desplegar en Netlify a través de la interfaz del sitio web o de la CLI de Netlify.

## Configuración del proyecto

Tu proyecto Astro puede desplegarse en Netlify de tres maneras diferentes: como un sitio estático, como un sitio renderizado en el servidor o como un sitio renderizado en el borde (edge).

### Sitio estático

Tu proyecto Astro es un sitio estático por defecto. No necesitas ninguna configuración adicional para desplegar un sitio estático de Astro en Netlify.

### Adaptador para renderizado bajo demanda

Añade [el adaptador de Netlify](/es/guides/integrations-guide/netlify/) para habilitar el renderizado bajo demanda en tu proyecto Astro y desplegarlo en Netlify con el siguiente comando `astro add`. Esto instalará el adaptador y realizará los cambios apropiados en tu archivo `astro.config.mjs` en un solo paso.

```bash
npx astro add netlify
```

<ReadMore>Consulta la [guía del adaptador de Netlify](/es/guides/integrations-guide/netlify/) para instalarlo manualmente en su lugar, o para ver más opciones de configuración, como desplegar el middleware de Astro de tu proyecto usando las Edge Functions de Netlify.</ReadMore>


## Cómo desplegar

Puedes desplegar en Netlify a través de la interfaz del sitio web o usando la CLI (interfaz de línea de comandos) de Netlify. El proceso es el mismo para los sitios Astro estáticos y para los que usan renderizado bajo demanda.

### Despliegue desde la interfaz del sitio web

Si tu proyecto está almacenado en GitHub, GitLab, BitBucket o Azure DevOps, puedes usar la interfaz del sitio web de Netlify para desplegar tu sitio Astro.

<Steps>
1. Haz clic en <kbd>Add a new site</kbd> en tu [panel de Netlify](https://app.netlify.com/)

2. Elige <kbd>Import an existing project</kbd>

    Cuando importes tu repositorio de Astro desde tu proveedor de Git, Netlify debería detectar y rellenar automáticamente los ajustes de configuración correctos por ti.

3. Asegúrate de que se hayan ingresado los siguientes ajustes y luego presiona el botón <kbd>Deploy</kbd>:

    - **Build Command (Comando de construcción):** `astro build` o `npm run build`
    - **Publish directory (Directorio de publicación):** `dist`

    Después de desplegar, serás redirigido a la página de resumen del sitio. Allí puedes editar los detalles de tu sitio.
</Steps>

Cualquier cambio futuro en tu repositorio de origen activará despliegues de vista previa y de producción según tu configuración de despliegue.

#### Archivo `netlify.toml`

Opcionalmente, puedes crear un nuevo archivo `netlify.toml` en el nivel superior del repositorio de tu proyecto para configurar tu comando de compilación y tu directorio de publicación, así como otros ajustes del proyecto, incluyendo variables de entorno y redirecciones. Netlify leerá este archivo y configurará tu despliegue automáticamente.

Para configurar los ajustes por defecto, crea un archivo `netlify.toml` con el siguiente contenido:

```toml
[build]
  command = "npm run build"
  publish = "dist"
```

### Despliegue con la CLI

También puedes crear un nuevo sitio en Netlify y vincular tu repositorio Git instalando y usando la [CLI de Netlify](https://cli.netlify.com/).

<Steps>
1. Instala la CLI de Netlify de forma global

    ```bash
    npm install --global netlify-cli
    ```

2. Ejecuta `netlify login` y sigue las instrucciones para iniciar sesión y autorizar a Netlify

3. Ejecuta `netlify init` y sigue las instrucciones

4. Confirma tu comando de construcción (`astro build`)

    La CLI detectará automáticamente los ajustes de construcción (`astro build`) y el directorio de despliegue (`dist`), y te ofrecerá generar automáticamente [un archivo `netlify.toml`](#archivo-netlifytoml) con esos ajustes.

5. Construye y despliega haciendo push a Git

    La CLI añadirá una clave de despliegue (deploy key) al repositorio, lo que significa que tu sitio se reconstruirá automáticamente en Netlify cada vez que hagas `git push`.
</Steps>

<ReadMore>Más detalles de Netlify sobre [cómo desplegar un sitio Astro usando la CLI de Netlify](https://www.netlify.com/blog/how-to-deploy-astro/#link-your-astro-project-and-deploy-using-the-netlify-cli) (en inglés)</ReadMore>

### Establecer una versión de Node.js

Si estás usando una [imagen de construcción](https://docs.netlify.com/configure-builds/get-started/#build-image-selection) heredada (Xenial) en Netlify, asegúrate de que tu versión de Node.js esté establecida. Astro requiere `v22.12.0` o superior.

Puedes [especificar tu versión de Node.js en Netlify](https://docs.netlify.com/configure-builds/manage-dependencies/#node-js-and-javascript) usando:
- un archivo [`.nvmrc`](https://github.com/nvm-sh/nvm#nvmrc) en tu directorio base.
- una variable de entorno `NODE_VERSION` en los ajustes de tu sitio usando el panel de proyecto de Netlify.

## Usar Netlify Functions

No se requiere ninguna configuración especial para usar Netlify Functions con Astro. ¡Añade un directorio `netlify/functions` en la raíz de tu proyecto y sigue [la documentación de Netlify Functions](https://docs.netlify.com/functions/overview/) para comenzar!
