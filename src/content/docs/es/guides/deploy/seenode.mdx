[Seenode](https://seenode.com) es una plataforma de despliegue para construir y desplegar aplicaciones web con bases de datos, con observabilidad incorporada y escalado automático. Los sitios de Astro pueden ser desplegados en Seenode usando renderizado del lado del servidor (SSR).

Esta guía incluye instrucciones para el despliegue en Seenode a través de su interfaz web.

## Configuración del Proyecto

### Adaptador para SSR

Para habilitar el renderizado bajo demanda de tu proyecto de Astro y desplegarlo en Seenode, agrega [el adaptador de Node.js](/es/guides/integrations-guide/node/) con el siguiente comando `astro add`. Esto instalará el adaptador y realizará los cambios apropiados en tu archivo `astro.config.mjs` en un solo paso.

<PackageManagerTabs>
  <Fragment slot="npm">
  ```shell
  npx astro add node
  ```
  </Fragment>
  <Fragment slot="pnpm">
  ```shell
  pnpm astro add node
  ```
  </Fragment>
  <Fragment slot="yarn">
  ```shell
  yarn astro add node
  ```
  </Fragment>
</PackageManagerTabs>

Después de instalar el adaptador, actualiza tu archivo `astro.config.mjs` para configurar el servidor con los requerimientos de Seenode:

```js title="astro.config.mjs" ins={6-11}
import { defineConfig } from 'astro/config';
import node from '@astrojs/node';

export default defineConfig({
  output: 'server',
  adapter: node({
    mode: 'standalone'
  }),
  server: {
    port: process.env.NODE_ENV === 'production' ? (Number(process.env.PORT) || 80) : 4321,
    host: true
  }
});
```

Actualiza tu `package.json` para agregar un script de inicio que ejecute el servidor compilado:

```json title="package.json" ins={6}
{
  "scripts": {
    "dev": "astro dev",
    "build": "astro build",
    "preview": "astro preview",
    "start": "NODE_ENV=production node ./dist/server/entry.mjs"
  }
}
```

<ReadMore>Revisa [la guia de despliegue de Astro de Seenode](https://seenode.com/docs/frameworks/javascript/astro/) para más opciones de configuración y resolución de problemas.</ReadMore>

## Cómo Desplegar

Puedes desplegar en Seenode usando la interfaz web conectando tu repositorio de Git.

### Despliegue en su Interfaz Web

<Steps>
1. Crea una [cuenta de Seenode](https://cloud.seenode.com) e inicia sesión.

2. Sube tu código a tu repositorio de Git (GitHub o GitLab).

3. Desde el [Panel de Seenode](https://cloud.seenode.com/dashboard/applications/web/create), crea un nuevo **Web Service** y conéctalo con tu repositorio.

4. Seenode detectará automáticamente tu proyecto de Astro. Configura las opciones de despliegue:

   - **Comando de Compilación:** `npm ci && npm run build` (o usa los equivalentes de `pnpm` / `yarn`)
   - **Comando de Inicio:** `npm start`
   - **Puerto:** `80` (necesario para servicios web)

5. Selecciona el tamaño de instancia que prefieras y da clic en **Create Web Service**.

6. Tu aplicación será compilada y desplegada. Una vez completado, recibirás una URL para acceder a tu sitio de Astro en producción, tras lo cual podrás vincular tu dominio.
</Steps>
