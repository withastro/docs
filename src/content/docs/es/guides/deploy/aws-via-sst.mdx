Puedes desplegar un sitio Astro en AWS usando [SST](https://sst.dev), un framework de código abierto para desplegar aplicaciones full-stack modernas con soporte para SSG y SSR.

También puedes usar componentes adicionales de SST como cron jobs, Buckets, Queues, etc., manteniendo la seguridad de tipos.

## Inicio rápido

<Steps>
1. Crea un proyecto de Astro.

2. Ejecuta `npx sst@latest init`.

3. Debería detectar que estás usando Astro y pedirte confirmación.

4. Una vez que estés listo para el despliegue, puedes ejecutar `npx sst deploy --stage production`.
</Steps>

También puedes leer [el tutorial completo de Astro en AWS con SST](https://sst.dev/docs/start/aws/astro) que te guiará a través de los pasos.

### Componentes de SST

Para usar cualquier [componente adicional de SST](https://sst.dev/docs/), agrégalo a `sst.config.ts`. 

```ts {1} {5} title="sst.config.ts"
const bucket = new sst.aws.Bucket("MyBucket", {
  access: "public",
});
new sst.aws.Astro("MyWeb", {
  link: [bucket],
});
```

Y luego accede a ellos en tu archivo `.astro`.

```astro
---
import { Resource } from "sst"
console.log(Resource.MyBucket.name)
---
```

Consulta la [documentación de SST sobre vinculación de recursos](https://sst.dev/docs/linking) para obtener más información.

Si tienes alguna pregunta, puedes [preguntar en el Discord de SST](https://discord.gg/sst).
