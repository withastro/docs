Puedes usar [Vercel](http://vercel.com/) para desplegar un sitio Astro en su red global de borde (edge) sin ninguna configuración.

Esta guía incluye instrucciones para desplegar en Vercel a través de la interfaz del sitio web o de la CLI de Vercel.

## Configuración del proyecto

Tu proyecto Astro puede desplegarse en Vercel como un sitio estático o como un sitio renderizado en el servidor.

### Sitio estático

Tu proyecto Astro es un sitio estático por defecto. No necesitas ninguna configuración adicional para desplegar un sitio estático de Astro en Vercel. 

### Adaptador para renderizado bajo demanda

Añade [el adaptador de Vercel](/es/guides/integrations-guide/vercel/) para habilitar el [renderizado bajo demanda](/es/guides/on-demand-rendering/) en tu proyecto Astro con el siguiente comando `astro add`. Esto instalará el adaptador y realizará los cambios apropiados en tu archivo `astro.config.mjs` en un solo paso.

<PackageManagerTabs>
  <Fragment slot="npm">
  ```shell
  npx astro add vercel
  ```
  </Fragment>
  <Fragment slot="pnpm">
  ```shell
  pnpm astro add vercel
  ```
  </Fragment>
  <Fragment slot="yarn">
  ```shell
  yarn astro add vercel
  ```
  </Fragment>
</PackageManagerTabs>

<ReadMore>Consulta la [guía del adaptador de Vercel](/es/guides/integrations-guide/vercel/) para instalarlo manualmente en su lugar, o para ver más opciones de configuración, como desplegar el middleware de Astro de tu proyecto usando Vercel Edge Functions.</ReadMore>

## Cómo desplegar

Puedes desplegar en Vercel a través de la interfaz del sitio web o usando la CLI (interfaz de línea de comandos) de Vercel. El proceso es el mismo para los sitios Astro estáticos y para los que usan renderizado bajo demanda.

### Despliegue desde la interfaz del sitio web

<Steps>
1. Sube tu código a tu repositorio Git en línea (GitHub, GitLab, BitBucket).

2. [Importa tu proyecto](https://vercel.com/new) en Vercel.

3. Vercel detectará Astro automáticamente y configurará los ajustes correctos.

4. ¡Tu aplicación está desplegada! (p. ej. [astro.vercel.app](https://astro.vercel.app/))
</Steps>

Después de que tu proyecto haya sido importado y desplegado, todos los push posteriores a ramas generarán [Preview Deployments](https://vercel.com/docs/concepts/deployments/preview-deployments) (despliegues de vista previa), y todos los cambios realizados en la rama de producción (comúnmente “main”) resultarán en un [Production Deployment](https://vercel.com/docs/concepts/deployments/environments#production) (despliegue de producción).

<ReadMore>Aprende más sobre la [integración con Git](https://vercel.com/docs/concepts/git) de Vercel.</ReadMore>

### Despliegue con la CLI

<Steps>
1. Instala la [CLI de Vercel](https://vercel.com/cli) y ejecuta `vercel` para desplegar.

    <PackageManagerTabs>
      <Fragment slot="npm">
      ```shell
      npm install -g vercel
      vercel
      ```
      </Fragment>
      <Fragment slot="pnpm">
      ```shell
      pnpm add -g vercel
      vercel
      ```
      </Fragment>
      <Fragment slot="yarn">
      ```shell
      yarn global add vercel
      vercel
      ```
      </Fragment>
    </PackageManagerTabs>

2. Vercel detectará Astro automáticamente y configurará los ajustes correctos.

3. Cuando te pregunte `Want to override the settings? [y/N]`, elige `N`.

4. ¡Tu aplicación está desplegada! (p. ej. [astro.vercel.app](https://astro.vercel.app/))
</Steps>

### Configuración del proyecto con `vercel.json`

Puedes usar `vercel.json` para sobrescribir el comportamiento por defecto de Vercel y para configurar ajustes adicionales. Por ejemplo, puede que quieras añadir cabeceras a las respuestas HTTP de tus despliegues. 

<ReadMore>Aprende más sobre la [configuración de proyectos de Vercel](https://vercel.com/docs/project-configuration).</ReadMore>
