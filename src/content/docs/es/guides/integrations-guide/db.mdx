:::caution[Eliminado]
La integración de Astro DB fue declarada obsoleta en la v6.4 y ha sido eliminada desde Astro v7.0.

Si estabas usando esta integración en tu proyecto, te recomendamos migrar a una biblioteca de terceros para la funcionalidad de base de datos. Consulta la [guía de migración a Astro v7.0](/es/guides/upgrade-to/v7/#removed-astrojsdb) para obtener más detalles y recomendaciones sobre cómo actualizar tu proyecto.
:::
