Crea un [plugin de mdast](/es/guides/markdown-content/#markdown-processor-plugins) que añada una propiedad de tiempo de lectura al frontmatter de tus archivos Markdown o MDX. Usa esta propiedad para mostrar el tiempo de lectura en cada página.

## Receta

<Steps>

        - [`satteri`](https://www.npmjs.com/package/satteri) para crear un [plugin de `mdast` de Sätteri](https://satteri.bruits.org/docs/plugins/#mdast-plugins)

2. Crea un plugin de mdast.

    Este plugin recupera el texto del archivo Markdown. Luego, este texto se pasa al paquete `reading-time` para calcular el tiempo de lectura en minutos.

    <MarkdownProcessorTabs>
      <Fragment slot="satteri">
        ```js title="src/mdast/mdast-reading-time.ts"
        import getReadingTime from "reading-time";
        import { defineMdastPlugin } from "satteri";

        export const mdastReadingTimePlugin = defineMdastPlugin({
          name: "mdast-reading-time",
          after(root, context) {
            const textOnPage = context.textContent(root);
            const readingTime = getReadingTime(textOnPage);

            if (context.data.astro !== undefined) {
              // readingTime.text nos dará los minutos de lectura como una cadena amigable,
              // por ejemplo, "3 min read"
              context.data.astro.frontmatter.minutesRead = readingTime.text;
            }
          },
        });
        ```
      </Fragment>
      <Fragment slot="unified">
        ```js title="remark-reading-time.mjs"
        import getReadingTime from "reading-time";
        import { toString } from "mdast-util-to-string";

        export function remarkReadingTime() {
          return function (tree, { data }) {
            const textOnPage = toString(tree);
            const readingTime = getReadingTime(textOnPage);
            // readingTime.text nos dará los minutos de lectura como una cadena amigable,
            // por ejemplo, "3 min read"
            data.astro.frontmatter.minutesRead = readingTime.text;
          };
        }
        ```
      </Fragment>
    </MarkdownProcessorTabs>

3. Añade el plugin a tu configuración:

    <MarkdownProcessorTabs>
      <Fragment slot="satteri">
        ```js title="astro.config.mjs" {1,3,7-9}
        import { satteri } from "@astrojs/markdown-satteri";
        import { defineConfig } from "astro/config";
        import { mdastReadingTimePlugin } from "./src/mdast/mdast-reading-time";

        export default defineConfig({
          markdown: {
            processor: satteri({
              mdastPlugins: [mdastReadingTimePlugin],
            }),
          },
        });
        ```
      </Fragment>
      <Fragment slot="unified">
        ```js title="astro.config.mjs" {1,3,7-9}
        import { unified } from "@astrojs/markdown-remark";
        import { defineConfig } from "astro/config";
        import { remarkReadingTime } from "./remark-reading-time.mjs";

        export default defineConfig({
          markdown: {
            processor: unified({
              remarkPlugins: [remarkReadingTime],
            }),
          },
        });
        ```
      </Fragment>
    </MarkdownProcessorTabs>

    Ahora todos los documentos de Markdown tendrán una propiedad `minutesRead` calculada en su frontmatter.

4. Mostrar el tiempo de lectura

    Si las publicaciones de tu blog están almacenadas en una [colección de contenido](/es/guides/content-collections/), accede a [la propiedad `remarkPluginFrontmatter` desde la función `render()`](/es/reference/modules/astro-content/#render). Luego, renderiza `minutesRead` en tu plantilla allí donde quieras que aparezca.

    ```astro title="src/pages/posts/[slug].astro" "const { Content, remarkPluginFrontmatter } = await render(entry);" "<p>{remarkPluginFrontmatter.minutesRead}</p>"
    ---
    import { getCollection, render } from "astro:content";

    export async function getStaticPaths() {
      const blog = await getCollection("blog");
      return blog.map((entry) => ({
        params: { slug: entry.id },
        props: { entry },
      }));
    }

    const { entry } = Astro.props;
    const { Content, remarkPluginFrontmatter } = await render(entry);
    ---

    <html>
      <head>
        <meta charset="utf-8" />
        <title>{entry.data.title}</title>
      </head>
      <body>
        <title>{entry.data.title}</title>
        <p>{remarkPluginFrontmatter.minutesRead}</p>
        <Content />
      </body>
    </html>
    ```

    Si estás usando una [plantilla de Markdown](/es/basics/layouts/#plantillas-de-markdown), usa la propiedad `minutesRead` del frontmatter desde `Astro.props` en tu plantilla de maquetado.

    ```astro title="src/layouts/BlogLayout.astro" "const { minutesRead } = Astro.props.frontmatter;" "<p>{minutesRead}</p>"
    ---
    const { minutesRead } = Astro.props.frontmatter;
    ---

    <html>
      <head>
        <meta charset="utf-8" />
      </head>
      <body>
        <p>{minutesRead}</p>
        <slot />
      </body>
    </html>
    ```
