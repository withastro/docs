Astro se basa en Vite y es compatible tanto con plugins de Vite como de Rollup. Esta receta utiliza un plugin de Rollup para añadir la capacidad de importar un archivo YAML (`.yml`) en Astro.

## Receta

<Steps>
1. Instala `@rollup/plugin-yaml`:

    <PackageManagerTabs>
        <Fragment slot="npm">
        ```shell
        npm install @rollup/plugin-yaml --save-dev
        ```
        </Fragment>
        <Fragment slot="pnpm">
        ```shell
        pnpm add @rollup/plugin-yaml --save-dev
        ```
        </Fragment>
        <Fragment slot="yarn">
        ```shell
        yarn add @rollup/plugin-yaml --dev
        ```
        </Fragment>
    </PackageManagerTabs>

2. Importa el plugin en tu archivo `astro.config.mjs` y añádelo a la lista de plugins de Vite:

    ```js title="astro.config.mjs" ins={2,5-7}
    import { defineConfig } from 'astro/config';
    import yaml from '@rollup/plugin-yaml';

    export default defineConfig({
      vite: {
        plugins: [yaml()]
      }
    });
    ```

3. Finalmente, puedes importar datos YAML utilizando una sentencia `import`:

    ```js
    import yml from './data.yml';
    ```

    :::note
    Aunque ahora puedes importar datos YAML en tu proyecto Astro, tu editor no proporcionará tipos para los datos importados. Para añadir tipos, crea o busca un archivo `*.d.ts` existente en el directorio `src` de tu proyecto y añade lo siguiente:
    ```ts title="src/files.d.ts"
    // Especifica la extensión de archivo que deseas importar
    declare module "*.yml" {
      const value: any; // Añade definiciones de tipos aquí si lo deseas
      export default value;
    }
    ```
    Esto permitirá que tu editor proporcione sugerencias de tipos para tus datos YAML.
    :::
</Steps>
