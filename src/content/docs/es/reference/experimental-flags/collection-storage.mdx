<p>

  **Tipo:** `"single-file" | "chunked" | { type: "chunked", chunkSize: number }`<br />
  **Predeterminado:** `"single-file"`<br />
  <Since v="7.1.0" />
</p>

Esta funcionalidad experimental te permite cambiar cómo se almacenan los datos de las colecciones de contenido. 

Por defecto, Astro almacena estos datos en un único archivo en `.astro/data-store.json`. Cuando se establece en `"chunked"`, Astro divide los datos en múltiples archivos dentro de la carpeta `.astro/data-store/`.

```js title="astro.config.mjs" ins={5}
import { defineConfig } from "astro/config";

export default defineConfig({
  experimental: {
    collectionStorage: "chunked"
  }
});
```

En el modo fragmentado (`chunked`), los archivos se dividen en múltiples fragmentos. Astro crea un nuevo fragmento cuando el fragmento actual es mayor a 20 MB.

Alternativamente, puedes cambiar el límite. Esto es útil si tienes límites particulares establecidos por tu runtime o host.

El siguiente ejemplo reduce el límite a 1 MB:

```js title="astro.config.mjs" ins="chunkSize" ins={6-7}
import { defineConfig } from "astro/config";

export default defineConfig({
  experimental: {
    collectionStorage: {
      type: "chunked",
      chunkSize: 1024 * 1024
    }
  }
});
```

Esta opción se recomienda al desplegar en plataformas que tienen un límite de tamaño para recursos individuales.
