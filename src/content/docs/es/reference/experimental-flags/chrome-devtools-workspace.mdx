Habilita la [integración experimental del espacio de trabajo de Chrome DevTools](https://developer.chrome.com/docs/devtools/workspaces) para el servidor de desarrollo de Astro.

Esta función te permite editar archivos directamente en Chrome DevTools y hacer que esos cambios se reflejen en tu sistema de archivos local a través de una carpeta de espacio de trabajo conectada. Esto es útil para realizar modificaciones como ajustar valores de CSS sin salir de la pestaña del navegador.

Con esta función habilitada, ejecutar `astro dev` configurará automáticamente un espacio de trabajo de Chrome DevTools para tu proyecto. Luego, tu proyecto aparecerá como una [fuente de espacio de trabajo disponible que puedes conectar](#conectar-tu-proyecto). A partir de ahí, los cambios que realices en el panel "Sources" se guardarán automáticamente en el código fuente de tu proyecto.

Para habilitar esta función, añade la opción experimental `chromeDevtoolsWorkspace` a tu configuración de Astro:

```js title="astro.config.mjs" ins={4-6}
import { defineConfig } from 'astro/config';

export default defineConfig({
  experimental: {
    chromeDevtoolsWorkspace: true,
  },
});
```

## Conectar tu proyecto

Astro creará el archivo de configuración necesario para soportar los espacios de trabajo de Chrome DevTools. Sin embargo, tu proyecto también debe estar [conectado como una fuente](https://developer.chrome.com/docs/devtools/workspaces#manual-connection) para habilitar el guardado de archivos.

<Steps>

1. [Inicia el servidor de desarrollo de Astro](/es/develop-and-build/#iniciar-el-servidor-de-desarrollo-astro) con el comando de CLI apropiado para tu gestor de paquetes.

2. Navega a la vista previa de tu sitio (p. ej. `http://localhost:4321/`) en Chrome y abre DevTools.

3. En la pestaña **Sources** > **Workspaces**, encontrarás la carpeta de tu proyecto de Astro. Haz clic en **Connect** para añadir tu directorio como un espacio de trabajo.

</Steps>

Consulta la [documentación sobre espacios de trabajo de Chrome DevTools](https://developer.chrome.com/docs/devtools/workspaces#connect) para obtener más información.
