> **RedirectWithNoLocation**: La `Response` de redirección no tiene un encabezado `Location`. Usa `Astro.redirect()` para crear redirecciones, o agrega un encabezado `Location` a la `Response`.

## ¿Qué salió mal?

Un redireccionamiento debe tener una ubicación con el encabezado `Location`.
