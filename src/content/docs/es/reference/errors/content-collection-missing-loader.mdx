> **Ejemplo de mensaje de error:**<br/>
Las colecciones deben tener un `loader` definido. Revisa las definiciones de tus colecciones en tu archivo de configuración de contenido.<br/>

## ¿Qué salió mal?
A una colección de contenido le falta una definición de `loader`. Asegúrate de que cada colección en tu archivo de configuración de contenido tenga un `loader`.
Consulta la [documentación de colecciones de contenido](/es/guides/content-collections/) para obtener más información.
