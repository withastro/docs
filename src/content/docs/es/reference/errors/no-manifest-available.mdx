> Se llamó a `new FetchState(request)` fuera de un servidor de Astro, por lo que no hay ningún manifiesto disponible.

## ¿Qué salió mal?
`new FetchState(request)` solo se puede usar dentro de un servidor de Astro —la salida del servidor compilado o el servidor de desarrollo— donde Astro proporciona el manifiesto que describe tu sitio. Este error significa que fue llamado en otro lugar, por ejemplo, en un script básico de Node que importa `astro/fetch`.

Si este error ocurre dentro de un servidor compilado con Astro, por favor [abre una incidencia](https://astro.build/issues/).
