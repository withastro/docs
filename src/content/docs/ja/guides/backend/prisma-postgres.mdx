[Prisma Postgres](https://www.prisma.io/) は、モダンなWebアプリ向けに構築された、フルマネージドなサーバーレスPostgresデータベースです。

## Prisma ORMでの接続(推奨)

Prisma Postgresデータベースへの接続には、[Prisma ORM](https://www.prisma.io/orm)の使用を推奨しています。これにより、型安全なクエリ、マイグレーション、およびグローバルなパフォーマンスが提供されます。

このガイドではPrisma ORM 8を使用しています。Prisma ORM 7をお使いの場合は、代わりに[PrismaドキュメントのAstro向けPrisma ORM 7ガイド](https://www.prisma.io/docs/guides/v7/frameworks/astro)を参照してください。

### 前提条件
- [オンデマンドレンダリング(SSR)](/ja/guides/on-demand-rendering/)を有効にするためのアダプターがインストールされたAstroプロジェクト。
- [Astroの最小要件](/ja/install-and-setup/#前提条件)を満たすバージョンのNode.js。Node.js v24を使用している場合は、Prisma ORM 8の要件に合わせて`v24.11.0`以降を使用してください。

### 依存関係のインストールとPrismaの初期化

プロジェクトで次のコマンドを実行し、Prisma ORMのインストールとスターターファイルの作成を行います。

```bash
npx prisma@latest orm init --target postgres --authoring psl
```

これにより、`prisma`CLI、`@prisma/orm-postgres`、`dotenv`がインストールされ、以下のファイルが作成されます。
- `.env`から`DATABASE_URL`を読み込む`prisma.config.ts`ファイル
- スターターデータモデルを含む`src/prisma/contract.prisma`ファイル
- Prisma ORMクライアントをエクスポートする`src/prisma/db.ts`ファイル
- `.env.example`ファイル

すでにPrisma Postgresデータベースがある場合は、その接続文字列を`.env`に`DATABASE_URL`として追加してください。ない場合は、次のコマンドを実行してデータベースを作成し、接続文字列を自動的に書き込みます。

```bash
npx create-db@latest --env .env
```

このコマンドを実行すると、claim URLが出力されます。データベースを保持するには、そのURLを開いてサインインしてください。登録が行われないデータベースは24時間後にPrismaによって削除されます。

### モデルの定義

データベースのテーブルを作成するには、コントラクトに少なくとも1つのモデルを定義する必要があります。次の例では、プレースホルダーとして`Post`モデルを定義しています。まずは`src/prisma/contract.prisma`の内容をこのコードに置き換えてください。このモデルは、後から実際のデータ構造に合わせたモデルに削除・置換しても問題ありません。

```prisma title="src/prisma/contract.prisma"
// use prisma-8

model Post {
  id        Int     @id @default(autoincrement())
  title     String
  content   String?
  published Boolean @default(false)
}
```

ファイルの先頭にある`// use prisma-8`行は削除しないでください。この行は、ファイルで使用されているコントラクト構文をPrismaに伝える役割があります。Prisma ORMのセットアップ設定についての詳細は、[Prismaコントラクトリファレンス](https://www.prisma.io/docs/orm/contract-authoring/psl-syntax)を参照してください。

### コントラクトの出力

`src/prisma/db.ts`がインポートする型付きファイルを生成するため、次のコマンドを実行してください。コントラクトを変更した際にも、再度このコマンドを実行します。

```bash
npx prisma contract emit
```

### データベーステーブルの作成

コントラクトからテーブルを作成するため、次のコマンドを実行してください。これにより、データベースの状態を記録する`migrations/`ディレクトリも作成されます。

```bash
npx prisma db init
```

コマンドが`Connection terminated unexpectedly`で停止した場合は、作成したばかりのデータベースがまだ起動中です。数秒待ってから再度実行してください。

コントラクトを変更した際は、`npx prisma db update`を再度実行してデータベースに変更を適用してください。

### データのクエリと表示

`src/prisma/db.ts`からエクスポートされる`db`クライアントは一度だけ作成され、プロジェクト全体で再利用されます。モデルはPostgreSQLのスキーマごとにグループ化されているため、`Post`モデルには`db.orm.public.Post`としてアクセスできます。

次の例では、公開済みの投稿のみを`id`順で取得し、Astroテンプレートにタイトルと投稿内容を表示する方法を示しています。

```astro title="src/pages/posts.astro" {2, 4-7}
---
import { db } from '../prisma/db';

const posts = await db.orm.public.Post
  .where({ published: true })
  .orderBy((post) => post.id.desc())
  .all();
---

<html>
  <head>
    <title>公開済みの投稿</title>
  </head>
  <body>
    <h1>公開済みの投稿</h1>
    <ul>
      {posts.map((post) => (
        <li>
          <h2>{post.title}</h2>
          {post.content && <p>{post.content}</p>}
        </li>
      ))}
    </ul>
  </body>
</html>
```

クエリはAPIルートで処理するのがベストプラクティスです。AstroプロジェクトでのPrisma ORMの使用方法について詳しくは、[Astro + Prisma ORMガイド](https://www.prisma.io/docs/guides/frameworks/astro)および[データの読み取りに関するPrismaのガイド](https://www.prisma.io/docs/orm/fundamentals/reading-data)を参照してください。

## その他のORMやライブラリでの接続

お好みのORMやデータベースライブラリ、その他のツールを使用して、ダイレクトTCP経由でPrisma Postgresに接続することができます。まずはPrismaコンソールでダイレクト接続用の接続文字列を作成してください。

### 前提条件
- [オンデマンドレンダリング(SSR)](/ja/guides/on-demand-rendering/)を有効にするためのアダプターがインストールされたAstroプロジェクト。
- TCP接続が有効な接続文字列を持つ[Prisma Postgres](https://pris.ly/ppg)データベース。

### 依存関係のインストール

この例では、[`Node.js用のPostgreSQLクライアントであるpg`](https://github.com/brianc/node-postgres)を使用して、直接TCP接続を行います。

以下のコマンドを実行して`pg`パッケージをインストールします。

```bash
npm install pg
```

### データベースへのクエリ実行

`pg`クライアントに接続文字列を渡し、SQLサーバーと通信してデータベースからデータを取得します。

以下の例は、テーブルを作成してデータを挿入するもので、クエリURLとTCP接続の検証に使用できます。

```astro title="src/pages/index.astro" {2-19}
---
import { Client } from 'pg';
const client = new Client({ 
  connectionString: import.meta.env.DATABASE_URL,
  ssl: { rejectUnauthorized: false }
});
await client.connect();

await client.query(`
  CREATE TABLE IF NOT EXISTS posts (
    id SERIAL PRIMARY KEY,
    title TEXT UNIQUE,
    content TEXT
  );
  
  INSERT INTO posts (title, content)
  VALUES ('Hello', 'World')
  ON CONFLICT (title) DO NOTHING;
`);

const { rows } = await client.query('SELECT * FROM posts');
await client.end();
---

<h1>投稿一覧</h1>
<p>{rows[0].title}: {rows[0].content}</p>
```
