:::caution[非推奨]
Astro 4.0から非推奨となりました。エラーを返すフォールバックも含め、RSSヘルパーは削除されています。
:::

> **GetStaticPathsRemovedRSSHelper**: RSSヘルパーは`getStaticPaths`から削除されました。代わりに新しい@astrojs/rssパッケージを試してみてください。

## 何が問題か？

`getStaticPaths`はRSSフィードを生成するためのヘルパーを公開しなくなりました。代わりに[@astrojs/rss](/ja/recipes/rss/#setting-up-astrojsrss)インテグレーションに移行することをおすすめします。

**以下も参照してください:**
-  [RSSガイド](/ja/recipes/rss/)
