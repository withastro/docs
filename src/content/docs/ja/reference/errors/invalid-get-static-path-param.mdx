> **InvalidGetStaticPathParam**: `getStaticPaths()`のルーティングから無効な`params`の値が返されました。`object`である必要がありますが、`PARAM_TYPE`が返されました。

## 何が問題か？

`getStaticPaths()`の戻り値（オブジェクトの配列）の`params`プロパティもオブジェクトである必要があります。

```astro title="pages/blog/[id].astro"
---
export async function getStaticPaths() {
	return [
		{ params: { id: "ブログ" } },
		{ params: { id: "概要" } }
	];
}
---
```
